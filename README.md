# 宇的大观本地版

一个应用，同时使用 **考研数学 + 408 真题系统**。完整题库与运行环境一起打包，Windows 10 / 11 64 位无需安装 Node.js，首次使用也可断网。

## 下载与启动

从 [GitHub Release](https://github.com/diamond-pickaxe/cxy-mathos/releases/latest) 下载 Windows 便携 ZIP，完整解压到可写文件夹，双击 **宇的大观本地版.exe**。

程序自动打开统一首页：

- **数学**：进入数学一、数学二、数学三选择页，内置 7,083 道题与 1,639 张配图。
- **408**：直接进入本地 **真题总览**，内置 2009—2026 年 18 套试卷、846 道题。题目、答案、解析、配图和公式字体均已本地化。

保留启动小窗口；关闭小窗口或点击「退出程序」停止服务。不要只移动 EXE，runtime、public、library、data 等文件夹需一起保留。同一文件夹重复打开会唤起已运行的应用。

## 408 界面与功能

总览矩阵、知识点目录、导航和连续刷题页直接复用原站已加载的 CSS，来源与文件校验值见 [样式清单](library/cs408-styles.json)。为本地 DOM 移除了 Vue 的 data-v 样式作用域，并以少量 CSS 适配离线功能。

- 默认打开真题总览，可点击年份按整卷刷题，点击色块进入对应题目。
- 科目、章节、小节目录筛选，追加「全部题型 / 选择题 / 非选择题」。
- 连续列表与单题模式，答案解析、笔记、收藏、掌握状态和学习记录。
- 深浅色切换、做题计时与字号调整；小屏提供底部导航和目录抽屉。
- 408 的记录保存到应用文件夹，不随浏览器端口变化丢失。每次保存均有版本冲突保护，并保留上一份与每日备份。

## 数据与旧版记录

| 内容 | 本机位置 |
| --- | --- |
| 数学当前题库、目录与统计 | data/questions.json、data/categories.json、data/manifest.json |
| 数学学习记录 | data/progress.json |
| 数学自动备份 | data/backups/ |
| 408 学习记录 | data/408/progress.json |
| 408 自动备份 | data/408/backups/ |
| 数学发行快照 | library/bundled-library.json |
| 408 内置题库 | public/408/data.js |

两个题库的题号、笔记与进度独立保存。公开包不附带任何人的笔记、收藏、掌握记录或个人备份。

**从旧版升级：**先在旧数学与旧 408 页面分别导出学习记录；将合并版解压到新文件夹，再进入相应入口导入。旧版文件和浏览器记录不会自动删除。408 的导入位于右上角「本地」菜单。以后迁移电脑，可退出程序后复制整个文件夹。

数学的适用题数、题库导入格式和详细功能见 [数学说明](docs/math.md)。数学快照仍为去重 7,083 题，其中数一 5,959、数二 4,943、数三 5,109，共用题会重叠；另有 494 道未分科题目可从数学入口页查看。

## 开发与构建

源码运行需要 Node.js 22 或更新版本。运行应用无需 npm 依赖；jsdom 仅供开发测试。

~~~sh
npm ci --ignore-scripts
npm test
npm start
npm run release
~~~

源码启动地址为 http://127.0.0.1:4180/。便携版自动选择空闲端口，仅监听本机 127.0.0.1。打包时校验数学题库、全部图片、408 题库与原站样式，然后验证 EXE 在 PATH 中没有 Node.js 时仍可打开统一首页和两个入口。

发行脚本只从已校验的题库快照和资源白名单构建，不读取本机个人记录。请勿将 data/、备份、私有题库或账号配置提交到公开仓库。
