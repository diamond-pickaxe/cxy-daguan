# cxy-daguan

**宇的大观本地版**：考研数学与 408 离线刷题工具。

- 数学：7,083 道题，提供数学一、二、三入口。
- 408：2009—2026 年，846 道题，直接进入真题总览。
- 题目、答案、解析和配图离线可用，笔记、收藏与进度保存在本机。

[下载最新版](https://github.com/diamond-pickaxe/cxy-daguan/releases/latest)，内置完整题库，无需安装 Node.js。

- **Windows 10/11 64 位**：下载 `windows-x64-portable`，完整解压后双击 **宇的大观本地版.exe**。
- **macOS 13 或更新版本**：Apple 芯片选 `macos-arm64`，Intel 芯片选 `macos-x64`；解压后将 **宇的大观本地版.app** 放入“应用程序”并打开。当前未做 Apple 公证，首次打开可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”，详见 [Apple 说明](https://support.apple.com/zh-cn/102445)。

Windows 数据在应用旁的 `data` 文件夹；Mac 数据在 `~/Library/Application Support/cxy-daguan`，可从启动窗口打开。数学目录支持原地展开、手动学习标记及真题／非真题进度统计。

跨电脑或 Windows/Mac 迁移时，分别导出数学和 408 学习记录，在新设备对应入口导入。升级前建议备份；Mac 替换应用会保留原有数据目录。

来源：数学 [大观园](https://cxyonly.fans/)（原作者：潇澄宇）；[408 真题系统](https://www.408os.cn/overview)。非官方离线适配。
